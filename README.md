# JavaScript Learnings

## Description
This document outlines my key learnings in JavaScript. It includes the basic concepts, control structures, functions, and object/array handling techniques that I have studied.

## Key Concepts Learned

### Basics
- **Variables**: `let`, `const`, `var`
- **Data Types**: Strings, Numbers, Booleans, Arrays, Objects, Null, Undefined
- **Operators**: Arithmetic, Assignment, Comparison, Logical, Ternary

### Control Structures
- **Conditionals**: `if`, `else if`, `else`, `switch`
- **Loops**: `for`, `while`, `do...while`, `for...in`, `for...of`

### Functions
- **Function Declarations**: `function myFunction() {}`
- **Function Expressions**: `const myFunction = function() {}`
- **Arrow Functions**: `const myFunction = () => {}`
- **Parameters and Arguments**

### Objects and Arrays
- **Object Properties and Methods**
- **Array Methods**: `push`, `pop`, `shift`, `unshift`, `map`, `filter`, `reduce`, `forEach`
